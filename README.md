# NewIssuePreparator

A simple C# console application that writes "Hello World" to the console. This application is designed to be run as part of a GitHub Actions workflow.

## Project Structure

The solution is organized as follows:
- `/NewIssuePreparator` - Contains the main console application

## How it works

The application can be run manually through GitHub Actions workflow. The workflow will:
- Build the application
- Run it and output "Hello World" to the console

## Requirements

- .NET 9.0
- GitHub Actions (for automated builds and runs)
